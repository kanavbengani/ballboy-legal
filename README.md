# Ballboy Legal

Privacy Policy and Terms of Service for the Ballboy tennis fantasy app.

- [Privacy Policy](./privacy.md)
- [Terms of Service](./terms.md)
- [Account Deletion](./delete-account.md)

## Hosting

This repo is intended to be served via GitHub Pages. After pushing to GitHub:

1. Go to repo Settings → Pages
2. Set source to `main` branch, root folder
3. Public URLs will be:
   - `https://<github-username>.github.io/ballboy-legal/privacy`
   - `https://<github-username>.github.io/ballboy-legal/terms`
   - `https://<github-username>.github.io/ballboy-legal/delete-account`

These URLs go in:
- App Store Connect metadata (Privacy Policy URL field)
- Play Console (Data safety → account deletion URL: the `delete-account` page)
- The Ballboy app (Signup screen and Profile screen)

## Updating

Edit the markdown files and push. GitHub Pages rebuilds automatically. Bump the **Last updated** date at the top of any document you change.
